# Делись — прототип сайта

Статический прототип сайта «Делись»: рабочая вёрстка всех экранов на чистом HTML, CSS и JavaScript. Бэкенда нет, данные живут в `localStorage` браузера.

Живая версия: https://uklonskylaw-creator.github.io/delis-prototype/

## Что внутри

| Страница | Файл |
| --- | --- |
| Главная | `index.html` |
| Каталог объектов, поиск, фильтры, сортировка | `catalog.html` |
| О компании | `about.html` |
| Контакты | `contacts.html` |
| Вакансии | `vacancies.html` |
| Карточка объекта, версия для вошедшего | `pages/object.html` |
| Карточка объекта, версия для гостя | `pages/object-unreg.html` |
| Заявка на фиксацию клиента | `pages/fix-request.html` |
| Личный кабинет | `pages/cabinet/` |

Кабинет: вход, регистрация, сброс пароля, профиль публичный и приватный, объекты, избранное, клиенты, сотрудники.

## Структура

- `css/` — токены оформления и стили по разделам
- `js/` — общая логика, карточка объекта, избранное
- `data/` — демонстрационные объекты
- `images/` — изображения объектов и интерфейса

## Как смотреть локально

Откройте `index.html` в браузере. Рекомендуется Chrome.

Шрифты Google и карта Яндекса подгружаются из интернета. Без сети сайт работает, но шрифт и карта будут запасными.

## Отношение к боевому проекту

Боевая версия «Делись» живёт в отдельном закрытом репозитории `uklonskylaw-creator/delis`: Next.js фронт, админка, API на Bun, MongoDB. Этот репозиторий — прототип оформления, эталон для переноса в боевой код.
